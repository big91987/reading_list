## 已确认的任务边界

来源：Issue #76 原始需求与本轮用户工作区说明。

- 针对当前仓库的书籍清单页面，明显重做视觉布局及交互体验，不仅改颜色或按钮过渡。
- 视觉方向须先讨论，由用户选择，不由 Agent 自行定案。
- 保留既有管理能力和已保存数据；桌面、手机可用，动画不阻塞操作，尊重系统减少动态效果设置。
- 页面进入、条目出现、悬停或点击、筛选、标记已读、新增、删除是动效候选；设计阶段判断取舍。空状态、加载或操作反馈需统一设计。
- 需求批准后交设计；设计交付可直接查看和体验的原型，经用户确认后实施；开发用真实浏览器验证主要交互、响应式布局及动效，提供截图和可查看结果。
- Runner 负责任务分支和最终草稿 PR；本阶段不操作分支、提交、推送、PR 或 GitHub。

## 已查证的当前基线

证据为 2026-10-02 工作区源码阅读，不是本轮运行或浏览器验证。

- 页面范围：`app/index.html` 是单页“页间 · 读书清单”，包含页头、新增区、阅读统计、全部／未读／已读筛选、条目清单、空状态与页脚。当前不存在单本书详情页或封面管理入口。本次以该完整清单页为改造对象。
- 视觉：`app/styles.css` 为浅米色纸张、衬线字体、砖红强调色；桌面居中纵向面板及列表行，手机重排；目前只有少量颜色过渡，已有减少动态效果的过渡禁用规则。
- 管理：`app/app.js` 已实现新增、阅读状态双向切换、筛选、总数及已读数、删除、就地修改书名与保存／取消。新增成功切回全部；重命名保留当前筛选。
- 数据：使用浏览器 localStorage，键 `page-between-reading-list`，条目含书名和布尔已读状态；当前无账号、后端、云同步、检索、封面、作者、标签或评分。
- 校验与失败：空名、全清单不区分大小写重名被拒绝；修改排除自身；编辑输入上限为 80 个长度单位；存储写入失败不提交候选数据，显示失败，编辑失败保留草稿可重试。
- 上游：复用 `docs/04-implementation/tasks/71/prd.md` 与 `requirements-decisions.md` 已确认的书名修改规则、单编辑条目、显式保存与草稿退出规则，不再次审批。该任务的旧视觉延续要求属于 #71，本轮用户明确要求视觉重做，不将旧风格作为 #76 的固定方向。
