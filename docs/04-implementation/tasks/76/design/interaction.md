# 视觉与交互规范 v1

> 上游 A「现代编辑式书房」已接受。本文件的具体布局和动效已随 A-001 整体设计批准接受（用户「ok 继续推进吧」），不重开视觉方向。

## 1. 明显改版与区域组织

旧页是居中纵向页头 → 新增面板 → 列表行。新提案为轻量品牌刊头 → 桌面书房侧栏（引导语、阅读概览、新增）＋主书架（标题、筛选、卡片网格）。区域组织、横向书籍密度、排版层级均改变，不只是配色变化。

- 暖白 `#f7f6f2`，墨色 `#232823`，叶绿 `#46634e`，次级文字 `#656b63`，错误 `#9a3430`，分隔 `#dedfd6`。
- 系统字体；标题采用系统衬线候选，书名／控件用系统无衬线。无网络字体依赖。主标题 39px（手机 26px），书架标题 38px（手机 30px），书名 17px（手机 16px）。
- 最大内容宽 1440px，桌面外边距 48px、侧栏 292px、栏间距 64px；卡片间距 18px、10px 圆角。手机外边距 20px，卡片间距 14px。
- 卡片含装饰书籍图形、完整书名、阅读状态、常显修改／删除。装饰 aria-hidden，没有新增字段、真实封面、作者或可点击详情页。
- 状态由勾选框＋文字共同表达，不把已读书名划掉，不截断长名。统计基于全清单；细线表示已读数量占比，不表示单本阅读进度。

## 2. 响应式规则

| 宽度 | 页面结构 | 卡片与编辑 |
|---|---|---|
| ≥1200 | 概览／新增侧栏＋主书架 | 三列卡片；编辑卡片跨两列，为输入与错误提供空间 |
| 900～1199 | 较窄侧栏＋主书架 | 两列卡片；编辑跨两列 |
| 600～899 | 引导语与概览并排，新增在下一行，书架随后 | 两列卡片；编辑跨两列；768px 新增输入与按钮并排 |
| 320～599 | 顶部引导与简短概览，新增全宽，书架单列 | 图形靠左，完整书名与状态靠右，管理操作下一行；编辑恢复全宽 |

长名使用 overflow-wrap:anywhere，自然增高，不固定卡片高度截字。不固定侧栏或工具栏，不遮挡手机键盘／浏览器栏。触屏无需 hover 才出现入口；主要按钮、筛选、行操作与勾选 label 高度至少 44px。320/390/768/1440 为本轮验证宽度。

## 3. 管理与焦点

业务权威规则为 PRD BR-01～10 和 [契约](../../../../01-architecture/tasks/76/contracts.md)，本文件不另造规则。

- 新增成功：写入完成后追加未读书，切回全部，清空输入，焦点回新增输入；失败保留输入与列表。
- 修改：常显入口；进入就地表单并选中原名；最多一条编辑。桌面编辑横跨两列但保存不改变数据顺序。保存／取消回对应修改按钮；错误留在输入，关联 aria-describedby 和 role=alert。
- 编辑输入后的 Tab → 保存 → 取消 → 删除；组合输入期间不处理候选 Enter／Escape。明确提交校验原始长度 >80；历史超长书名可完整预填，拒绝超长保存但不截断原记录。
- 切筛选立即清草稿，焦点保留筛选按钮。阅读状态若使目标退出筛选，清其草稿并回当前筛选；目标仍在则保留草稿和 checkbox 焦点。
- 删除仅在写成功后移除；无新增确认弹窗或撤销能力。焦点到相邻有效修改入口／编辑输入，无相邻条目则当前筛选。编辑中删除目标不保存草稿。
- 全部清单通过 ul/li 表达，筛选按钮 aria-pressed；checkbox 名称包含书名及下一动作。状态与结果用 live region，不依赖颜色或运动。新操作清理上一个无关成功消息，失败保持可修正入口。

## 4. 动效取舍（A-001已批准）

统一缓动 cubic-bezier(.22,1,.36,1)。动画没有业务完成回调，不禁用输入，不覆盖控件的可点击性；每次重绘和系统偏好切换取消旧动画，以最新已提交结果为准。

| 场景 | 采用／省略、触发与完成 | 打断／减少动态效果 | 理由 |
|---|---|---|---|
| 初次进入 | 引导语 260ms，从 8px、0.5 opacity 到自然位置；首批卡片 220ms，从 6px、0.6 到自然位置 | 新动作重绘取消旧实例；减少模式直接完整显示 | 建立页面层次；控件自始可用 |
| 卡片出现 | 前12张最多 18ms 错峰，延迟上限72ms，总时长上限292ms；其余立即出现 | 不等待动画；连续重绘取消上一批 | 100 本不做线性累计长等待 |
| hover | 仅精细鼠标：卡片上移3px，边框／阴影180ms；操作仍常显 | 移出立即衔接；触屏无此效果；减少模式无位移 | 轻量层次，不暗示整卡可点击 |
| 按钮点击 | 按下时0.98缩放，140ms；松开归位 | 不等待缩放再提交；减少模式关闭 | 反馈按压，不用回弹或音效 |
| 筛选 | 数据和 aria-pressed 立即更新；选中底色140ms，首批结果卡片220ms浮现 | 新筛选取消旧实例；无退出层／旧书残影；减少模式即时更新 | 清晰表达内容变化而不淡出旧列表等待 |
| 已读双向切换 | 勾选与文字即时更新；概览已读占比线180ms变化 | 连续切换以最后成功写入为准；减少模式即时更新 | 省略划线／翻书／庆祝，避免误读和消耗 |
| 新增 | 成功写入后仅新卡片220ms浮现，不整批重播；全部筛选即时生效 | 新动作取消；减少模式即显 | 可定位新内容，无等待提交 |
| 删除 | 立即移除及重排，统计线180ms变化；**省略退出／塌缩动画** | 没有删除幽灵层／延迟提交；减少模式即改 | 保持连续删除与焦点简单可靠；不可逆操作不做装饰 |
| 进入／保存编辑 | 即时展开／恢复卡片；不动画输入框或 caret | 草稿与焦点独立于动效 | 优先输入法和键盘稳定 |
| 空、错误、成功 | 静态图形、文字＋颜色、原位反馈；无抖动、自动消失 toast | 减少模式保留所有文字 | 可阅读、可修正，读屏不重复宣布动画 |
| 加载 | **不采用骨架／spinner／人为延迟**；同步本地加载直接可用 | 不涉及等待 | 当前没有真实异步加载，不能假造状态 |

运行时系统偏好通过 matchMedia change 取消既有动画；CSS prefers-reduced-motion 禁用动画和 transition，关闭 hover 和 press 变换。演示开关仅辅助体验；系统偏好实际自动化验收仍属研发。

## 5. 关键状态矩阵

| 状态 | 内容／入口 | 恢复 |
|---|---|---|
| 正常混合 | 完整书名、已读勾选、全局概览、可见数量 | 各管理动作 |
| 整清单空 |「清单还是空的」「从一本真正想读的书开始吧。」 |「添加第一本书」聚焦新增 |
| 已读筛选无结果 |「还没有读完的书」「读完一本后，在这里为它打个勾。」 |「查看全部书籍」 |
| 未读筛选无结果 |「没有未读的书」「清单里的书都读完了，真不错。」 |「查看全部书籍」 |
| 空名／重名／过长 | 本输入附近明确错误，不提交 | 输入修正或取消 |
| 写入失败 | 明确“未能…”；原数据、输入／草稿保留 | 重试或取消，不能展示已保存成功 |
| 历史长名 | 完整自然换行，不截断不在加载时改写 | 就地编辑可缩短后保存 |
| 100 本 | 同一书架自然滚动，无分页或虚拟化承诺 | 动画数量封顶，操作即时 |

三个空状态和失败均有原型实测；截图与实际检查局限见设计验证报告。屏幕阅读器、真实输入法和真实触控设备尚未实测，不把浏览器小视口当真机验收。
