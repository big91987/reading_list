## 推荐体验顺序

1. 桌面看侧栏概览／新增与三列书架；缩窄为手机看单栏紧凑卡片。每张卡片的书籍图形是 CSS 装饰，不是真实封面。
2. 在全部／未读／已读间切换，新增两本不同书；修改书名、保存、刷新；取消或 Escape 退出草稿。
3. 双向标记阅读状态；在未读筛选中标已读，观察条目退出、全局统计变化与焦点回到筛选。
4. 展开页底「原型演示工具」，选择空清单、单本历史长书名、100 本夹具；尝试删除最后一本及编辑中删除。
5. 开启「模拟本地保存失败」，尝试新增／改名／状态／删除；关掉后重试。开启「演示减少动态效果」后重复操作，反馈仍可读。
6. 「检查布局与动效」读取真实 scrollWidth、clientWidth 和 CSS 样式；「检查动效与打断」读取浏览器动画实例、采样中间帧并取消旧实例，仅为审查诊断，不进入产品。

系统减少动态效果始终优先；演示开关只能额外关闭，不能强行开启系统已关闭的动画。真实系统偏好切换仍需要研发通过支持该环境的浏览器测试验证，不能以演示开关代替。
