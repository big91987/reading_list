# 筛选提示交互规范

权威产品规则：[PRD](../prd.md)。本文件确定呈现机制，不扩展需求。

| 入口（保持顺序） | 固定文案 |
|---|---|
| 全部 | 显示所有书籍 |
| 未读 | 只显示未读书籍 |
| 已读 | 只显示已读书籍 |

## 呈现与退出

支持悬停且精细指针环境中，进入按钮即显示，无定时器/人为延迟；只显示所悬停入口。上方浮层左边与按钮左边对齐，底边紧邻按钮顶边，无间隙，鼠标可移入浮层继续阅读，离开整个按钮（含浮层）即隐藏。12px、行高1.5、水平9px/垂直6px内边距、5px圆角；沿用现有深色墨色与浅色文字，无箭头、动画或阴影。绝对定位、层级2、单行 max-content，不改变过滤条、选中下划线、按钮 padding/gap 或列表位置。

Escape 在原有键盘行为之外隐藏当前提示，不 preventDefault，不阻止现有编辑取消；仅抑制本次悬停，pointerleave 清除抑制。点击仍走既有处理器，不主动关闭、不拦截也不延迟；只要鼠标仍在入口即可继续解释当前范围。刷新重新按浏览器当前指针状态判断，不承诺刷新自动重显。

## 名称、键盘、触屏

保留原生 button/type、标签、data-filter、aria-pressed、焦点样式、Tab 顺序与 Enter/Space 激活。浮层 span 为纯补充视觉文本、aria-hidden=true，不参加按钮可访问名称，不可聚焦、不建立新直播播报。需求不承诺键盘焦点触发提示，不添加 :focus 提示。无 hover 或粗指针环境禁用浮层；不使用长按或第一次触摸展示、第二次筛选的机制。

固定文案不含用户内容或数量。浮层有无与数据/选中状态无关，空清单、无结果、编辑及撤销区域不调整规则。样式加载失败时只降级为原有按钮/筛选能力，不添加数据恢复或提示错误消息。

## 设计验证与研发验证边界

原型已覆盖混合、空清单、两类无结果、原名称激活、Escape、离开旧入口隐藏、320px布局与存储保持。注册 Chromium 实测，不扩大到 Safari/Firefox 通过声明。移入浮层持续可读、纯 hover 停留不点击、真实触屏、屏幕阅读器和跨引擎由研发执行；详见 [验证报告](../../../../05-validation/tasks/94/design-validation.md)。要求研发对照产品基线核对正常布局，无新增横向溢出（至少320/390/1440px）。
