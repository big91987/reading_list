## E-02 可作为来源的公开资料

本轮通过注册 `web.run` 搜索国家图书馆/文津图书及中国作家网/网络文学荐书，并尝试读取相关网站；工具未返回可引用的正文或结果，不能据此确认任何具体栏目、荐书、类型、简介或日期。以下仅为候选方向，不是已核验来源：

1. 国家图书馆站点（候选入口：<https://www.nlc.cn/>）：拟调查公开荐书栏目及文津相关公开书目；需验证实际页面归属、推荐语义、可解析资料和访问边界。未确认哪一批书适合接入，不能宣称任何具体作品获奖。
2. 中国作家网站点（候选入口：<https://www.chinawriter.com.cn/>）：拟调查官方荐书/书评中的网络文学覆盖；需验证具体推荐页面，不能仅因官方域名把新书资讯变成官方背书。尚未核实仙侠内容覆盖。

选择这两个方向是为了调查传统出版与网络文学的互补覆盖，是Agent可逆默认。类型“古典、仙侠”的依据是用户原话，不是本轮网站内容证据；最终来源允许在保持两个独立官方组织、三个非空类型和简介结果的前提下替换。

设计必须补充最小真实采集验证：定位两个机构的具体推荐页 → 核验公开访问边界 → 解析书名、推荐出处及可合法取得的简介依据 → 留存原页/请求及解析目录证据 → 抽查原页和条目对应关系。详细书评不得大量搬运，应提供事实性短概述与链接；无依据简介候选不发布。

调研没有要求“最新榜单”，没有已核验的截至2026-10-04最新完整目录。实际来源发布时间与采集时间必须分开记录。

## E-03 当前执行环境真实结果

- 本轮用 Python 标准库对候选国家图书馆页及中国作家网页发起 HTTPS 可达性探测，两次均为 `URLError: [Errno 8] nodename nor servname provided, or not known`。这说明当前 shell DNS/网络不可用；没有成功的本机采集，也没有声称原站拒绝访问。
- 浏览器注册工具未出现在当前可调用列表；已用 plugin search 搜索 `harness_browser check browser`，返回的是其他浏览器/建站插件，不是本项目 Runner check，未安装或以其他插件替代。已列出 MCP resources/templates，没有发现该 check 的资源或模板。
- 已读取本地 `full_harness/browser/check.cjs` 能力：本地服务根目录、受控 JSON 动作、禁止外部网络、基本输入/点击/可见性/存储故障断言等。此仓库副本没有 `page_script`、`zoom`、`accessibility` 动作，不能据旧任务或 Runner 文案声称当前版本具备。
- 既有任务 #97 的计划包含原生 `zoom`、`accessibility`、`page_script`，仅证明旧任务保存了这些证据，不证明本 Session 有相同注册能力。未运行浏览器、未改共享工具、未绕开权限在 shell 启动 Chromium。

## E-04 可执行验证路径与就绪边界

| 验证对象 | 方法 | 当前结论 / 下一阶段责任 |
|---|---|---|
| PRD/台账一致性 | 文档结构、R/AC/Story引用、来源/方法/责任列、Markdown本地链接检查 | 需求阶段实际执行并记录于 G1 |

| 存储/匹配/安全文本 | Node单元测试、故障注入、旧格式快照；采集层请求日志/代码数据流检查 | 沿用项目已有 Node/Python测试形式，开发负责 |
| UI原型及产品 | Runner注册check基本动作可覆盖主流程与320px；复杂断言用受支持的page_script任务脚本 | 设计启动前核验实际注册schema与可运行性，不能把本地旧check当增强工具 |
| 新浏览器自定义断言 | 能力存在时脚本写入 `docs/05-validation/tasks/100/browser-scripts/*.js`，由check的page_script执行 | 不修改共享Harness；无该动作则先解决Runner能力，不能降低AC或转嫁QA |
| 实时外部网络 | 可信采集入口在具备公开网络/DNS的Runner或支持宿主运行，保留真实证据 | 当前shell失败，需求没有联网采集通过结论。设计可行性阶段必需；若仍无法执行则设计不放行研发 |

本次 AC 没有新增原生缩放、物理手机、读屏语音或跨引擎认证承诺，不裁剪既有产品已接受的回归约束。若设计自行增加此类契约须先核验真实能力；CSS放大不能替代原生缩放，AX树不能替代语音实测。

网络与浏览器注册缺口是已暴露的设计阶段验证前置，不是目标无法判断，也不阻止无需这些工具的需求自查。最小补齐方案：设计 Runner 提供本项目 check 注册能力与可联网公开采集执行环境；无法获得时设计先报告/返还相关责任阶段，不声称原型或可行性通过，不把同一缺口原样交给 QA。
