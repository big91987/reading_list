# 页间 · Issue #100 可运行设计原型

运行依赖：静态HTML/CSS/JS与catalogue.json，现代浏览器；无需npm/API密钥/外部请求。可在仓库根运行：

```sh
python3 -m http.server 8000 --directory docs/04-implementation/tasks/100/prototype
```

打开本机8000端口；Runner验证用已注册check（root为本目录），不自行启动Chromium。不要与产品origin混用；专用键`issue-100-prototype-books`只承载演示书单，不读写实际`page-between-reading-list`。清除该演示键/全新浏览器可复位，刷新只保已保存书单，撤销记录随刷新失效。

## 内容与关键状态

正常目录6条取自上游真实两源34条PoC的子集，跨历史社科/现当代文学/科普。catalogue.json只含重新撰写的事实性短简介及原页链接，不含研究原文、封面、网页快照。作者、原门类、原页和采集时间来自证据；未核验来源发布日期，显示未知，不从URL推断日期。此子集不充当生产自动目录或最新榜单。

“梅西传”演示旧格式单候选、“旧书示例”无匹配、“同名示例”两歧义候选均为明确标注的测试数据；甲/乙不出现在正常官方推荐中。目录场景控制展示加载、有效空、过期、部分失败、全失败有/无缓存；切换场景不执行采集、不触发私人写入。生产运维入口是HLD CLI，不在用户页面提供采集按钮。

主路径：类型浏览→看简介/出处→主动加入→我的书单→编辑信息/候选确认→阅读→删除/撤销。重复加入提示不覆盖；存储失败保持原数据，编辑表单保草稿；无匹配可手填；多候选无预选；改名保留信息并显示待核对。

## 交互约定

- 保留页间米色/砖红视觉，两个按钮页签切换内容，推荐为新入口；本期不把推荐与私人条目混合排序。
- 页面操作使用原生button/select/input/textarea，Tab按DOM顺序，Enter触发按钮或保存，Escape取消当前编辑/关闭候选；关闭后焦点回该书操作入口。
- 编辑在条目内展开，只有一个编辑器；标题≤80、人工简介≤600、最多3个类型。推荐简介全量可读，不以截断省略唯一阅读入口。
- 单/多候选展示身份与出处，点击明确“确认采用”才补空缺；不自动选第一项，拒绝/查看不写。已有内容保留，原始类型与本产品类型不混淆。
- 各种目录结果用可访问status区，不用空列表代表错误；来源链接安全HTTPS、新窗noopener/noreferrer。控制区明确“非生产运维”。

## 原型与生产边界

原型使用任务静态数据与场景模拟，覆盖设计交互而非生产调度/采集/只读HTTP路由/缓存协议。生产需按contracts实现schema校验、网络超时/公共缓存、另标签页冲突、真正采集及完整回归；这些为明确开发必需任务，不能凭原型check免测。旧app和release未改动，原型不是上线变更。
