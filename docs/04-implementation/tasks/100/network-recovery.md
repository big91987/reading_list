## 1. 授权与原因修正

用户明确告知：此前DNS错误来自Codex的 `sandbox network_access=false`，不是缺少远程Runner；平台通过正式管理员接口允许本任务既有requirements/design会话联网，并接通不足权限时的原生管理员审批。本轮开发者权限也明确网络已启用。

本轮直接使用原会话现有终端与Python，不申请新环境、不安装远程插件、不新建付费服务、不改保护配置。D-008按该实际回答和恢复证据收口；旧“请选择远程/本机入口”请求不再有效，也不再要求用户回答普通阶段确认。

## 3. 首批来源与内容边界（D-009）

- 中国作家网：官方“文学好书”专题明确征集/评议机制，且链接到2026年第四期入围书单；具体页含30部作品、文学门类、作者和文字“推荐语”。记录状态为“文学好书入围书单”，不称全部获选、获奖或截至当前的最新榜单。实测门类含长篇小说、中短篇小说、散文/随笔、理论评论、科幻、非虚构/纪实；科幻不等于仙侠。
- 福建省图书馆：官网“新书推荐”链接到四个具体书目详情，具有题名、作者、索书号和文字简介。本产品类型映射依据这些索书号，明确不是机构正式类型：K/F等映射历史社科，I映射现当代文学，B84-49心理学普及读物映射科普。
- 国家图书馆：虽首页和版权声明可访问，声明涉及转载/引用署名、内容修改和采集权益限制；保守默认不将其纳入自动接入源，除非后续取得适当依据。按已接受D-002“候选可等价替换”采用福建省图书馆，不降低“两源、三类型、真实简介”条款。
- 两个入选站robots.txt均404，只说明未取得该入口的规则，不是采集或再发布许可。已读取福建馆法律声明、中国作家网页版权信息；未取得概括性书面授权，catalogue元数据明确 `permission_granted=false`，report未声明授权。正式产品仅元信息、原创事实性短简介及原页链接，不搬运长评、封面或全文；维护者按来源边界复核，遇限制或异议停源。研究响应和intro_evidence不是可原样上线的推荐数据包。
