# Issue #74 交互规范

状态：展示方案已获 A-001 批准；需求 D-001～005 已批准。依据实际 `app/`，不新增搜索。

## 展示与响应式

三个原生按钮保持“全部 / 未读 / 已读”顺序；名称后一个空格和精确十进制整数，如“全部 3 / 未读 2 / 已读 1”。不增加胶囊徽标、图表、百分比或“99+”。沿用纸色背景、衬线字体、原文字颜色、当前选中按钮红色底线；数字继承按钮颜色，使用等宽数字特性，不单独缩小。顶部摘要保留。

按钮名称与数量构成同一点击目标；最小高度 44px，数字不换行、不截断。筛选区允许整按钮换行，保持 DOM 顺序，不引入横向滚动。沿用 430px 以下均分按钮及既有间距；超出单行时整按钮换行，不对可保存书单设置新上限。实际代码主布局断点为 650px（不是 PRD 描述中的 640px）；本轮同时检查 640/641 和真实 650/651 两侧，另检查 320、430、431、1280。

## 关键交互状态

| 状态／动作 | 展示与反馈 |
|---|---|
| 打开样例 | 全部 3、未读 2、已读 1；全部选中 |
| 选择已读／未读 | 只改变列表和选中态，三个数仍 3/2/1 |
| 新增未读书成功 | 全部和未读各 +1，沿用新增返回全部、输入框焦点规则 |
| 删除成功 | 总量和所属分类各 -1，沿用下一条或筛选区焦点回退 |
| 双向切换阅读状态 | 总量不变，两类一增一减；条目移出当前分类也更新全部按钮 |
| 书名编辑、取消或编辑错误 | 数量不变，原编辑／错误提示／焦点行为不变 |
| 空集合 | 三个 0，仍可选筛选；原“清单还是空的”文案保留 |
| 分类为零但集合非空 | 零分类仍可选，原分类空态文案保留；其他分类计数不变 |
| 校验或保存失败 | 不改集合、不改数量；沿用原提示，恢复后允许重试 |
| 刷新 | 按原加载规则恢复有效集合，再算三个数；筛选仍按原规则回到全部 |

## 可访问性

保留 `role=group`、“筛选书籍”标签、原生 button 与 `aria-pressed`。数量是按钮可访问名称的一部分，不用 `aria-hidden` 隐藏数字，也不设置固定的仅名称 aria-label。只更新按钮内部 `.filter-count` 文本，不替换按钮节点，保持 Tab 顺序、焦点与监听。保留既有 `:focus-visible` 样式及顶部摘要／操作消息的 live-region，不增加三处重复播报。键盘 Tab/Enter/Space 使用原生语义。触摸点按与真实屏幕阅读器朗读由研发补充人工验证；浏览器自动点击不是物理手机触摸证明。
