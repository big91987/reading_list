## 1. 目标与系统上下文

本地浏览器读书清单为新用户解释三种范围。读者自主添加/标记/编辑/删除/撤销和筛选；Owner 负责支持反馈与最终合并/发布，研发实现与验证。范围仅三个固定提示，非目标沿用 PRD（无搜索、引导、数据迁移、后端、账号、埋点）。

```text
读者 ──指针进入/离开──> 按钮静态提示（HTML + CSS；临时 Escape 抑制）
     ──点击/键盘激活──> 既有筛选处理 ──> 内存 currentFilter ──> 列表/空状态
     ──书籍操作──────> 既有编辑/撤销与 persist ──> localStorage
浏览器加载同一组静态资源；无新增服务、外部请求、事件管道或运行任务
```

## 3. 模块与状态流程

HTML 负责三条静态解释；CSS 负责定位与 `(hover: hover) and (pointer: fine)` 下的可见性；少量页面事件负责 Escape 本次抑制及离开重置。以上不负责选择范围、书籍持久化或错误反馈。原 app.js 仍独占筛选/重绘和书籍操作的责任，不引入 Tooltip 服务或通用组件系统。

提示状态：隐藏→指针进入且能力匹配→可见→离开→隐藏；可见→Escape→本次抑制→离开重置→隐藏。提示可见性从指针/CSS 派生，只有抑制类存于当前DOM，无计时器、异步状态、幂等请求或恢复日志。重复 Escape 幂等；刷新清除抑制类。点击后筛选同步更新 currentFilter 与 aria-pressed，再 render；鼠标显示逻辑不参与该路径。新增/编辑/删除/撤销继续依既有 persist 成功后提交内存，错误保留原处理。

信息与事件契约见 [contracts.md](contracts.md)。无 API 变更、数据转换或公共 schema 版本提升。

## 4. 部署、信任和故障

沿用 app/index.html、styles.css、app.js 的静态部署单元，无新增包、CDN、网络服务、费用或凭据。原型在独立目录和独立存储键工作，演示夹具不进入产品。用户书名继续通过现有 textContent 展示；提示仅固定文本，不接受HTML/配置输入。

CSS 缺失可能令补充文字显示或提示失效，不影响 button 激活与数据格式；正常受支持环境要求不显示常驻帮助。无 hover 环境隐藏提示、直接筛选。Escape 监听不可 preventDefault 或消费现有取消动作。提示代码失败不调用 persist；localStorage 读取/写入失败沿用原功能错误边界。恢复仅重载静态资源或重新进入按钮，不引入业务重试队列。无独立数据面/控制面、身份或审计要求（单页本地形态）。

## 5. 质量属性与技术策略

| 属性 | 可验证承诺 |
|---|---|
| 清晰/非干扰 | 三条固定文案、进入立即显示、离开隐藏；不变选中状态、不位移 |

| 可访问性边界 | 原名称和 aria-pressed 不变、Tab/Enter/Space 保留；不宣称已完成屏幕阅读器或合规认证 |

主专业视角为小型浏览器交互与状态隔离，本阶段 Agent 自查，不启动额外评审模型。事实来自现有代码及注册 Chromium 原型；不推广到浏览器原生 title、跨引擎或真实触屏结论。候选比较与自主选择依据见 [决策台账](architecture-decisions.md)。纯静态提示是可逆的局部机制，不建独立 ADR（不满足难逆转门槛）。
