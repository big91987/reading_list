## 1. 全景与当前阶段

```text
已批准PRD / #71规则
        ↓
本次设计：可体验UI ──→ 用户整体设计审查（A-001）
```

本阶段回答页面怎样组织、动作如何反馈、数据由谁管理、失败怎样恢复。责任域指一类结果由谁说了算，例如“书名是否保存”由本地提交结果决定，而非卡片动画结束决定；责任划分记录于本HLD，不代表创建新服务或更换存储。

## 2. 目标、运营与架构驱动

目标为明显的现代编辑式书房布局和不阻塞的操作反馈，保护个人已有数据与全部管理动作。用户自行管理本浏览器清单；Owner批准需求、设计和风险，研发实现与验收，Runner负责最终发布任务分支及草稿PR。无账号、后端、同步、搜索或封面资产管理；详细非目标引用 PRD §5。

架构驱动：原键／JSON／顺序兼容；成功以写入为边界；单编辑草稿与筛选协调；动画可打断；系统减少动态效果；320～1440响应式；100本仅为验证负载。没有帧率、容量、跨设备可用性或云端恢复承诺。事实依据为当前 app/ 三文件及 #71 契约，不将历史计划等同当前代码。

## 4. 逻辑架构与流程

```text
用户（鼠标／键盘／触屏）
       ↓ 事件和输入
清单管理：校验 → 候选数组 ──→ 本地保存：setItem
       ↑                         │
       ├── 写失败：不提交 ←─────┤
       └── 写成功：替换内存 ←───┘
                  ↓
呈现与反馈：派生筛选/统计 → 重绘卡片 → 恢复焦点/播报
                  ↓
可选动画（取消旧实例 → 对最新节点启动，不回写业务）
```

调用／数据流：加载 getItem→解析容错→内存书籍→视图；动作同步校验→构造候选→setItem成功→内存提交→派生视图。运行控制流为浏览器事件顺序，没有服务器调和、队列或定时重试。动画时钟只管理呈现，结束不再提交、重删或重新插入。计量流不存在；已读数量为用户统计，不是收费／容量数据。观测为本地明确错误与阶段验证记录，不上传书名或新增遥测。

并发边界是单页同步事件循环：每个动作读取当前已提交数组，不使用动画开始时旧快照继续业务；写入失败原数组不变。重复新增由全清单去重拒绝；重命名原名允许；状态赋值为明确布尔目标，不在动画回调中反转。无跨标签页协调承诺。

## 5. 领域契约、状态与生命周期

详见 [contracts.md](contracts.md)。书籍没有新身份字段，现有对象引用用于一次会话中的目标定位；更新目标时同步编辑引用，不用标题作为稳定身份。编辑内部内存态持有 book/draft/error，不进入存储。删除先写入候选成功，再移除视图和恢复焦点。阅读状态移出筛选时退出编辑，仍在时保留草稿。筛选不改变持久书籍；成功新增切全部。

## 6. 部署、安全与故障边界

部署仍为 app/index.html + styles.css + app.js 静态站点，逻辑与存储均在同源浏览器；不增加网络请求、依赖包、字体或服务。本轮只构建独立原型，未改 app/。原型来源和隔离键见其README。

信任边界：书名／旧JSON是非可信输入，只用textContent或value写入用户字符串，禁止拼进innerHTML。统计的HTML只含派生数字；localStorage读取做原有类型过滤和容错，不借改版恢复／迁移坏数据。来源变化、私密模式和清除数据仍属浏览器存储边界，不宣称备份。

| 故障 | 用户结果／恢复责任 |
|---|---|
| 写入被拒／quota异常 | 本地保存返回失败；清单管理不提交；呈现保留输入与旧视图，用户重试 |
| JSON坏／读取失败 | 沿用已有容错显示可用空清单，不在加载时覆写存储；不承诺恢复损坏记录 |
| 动画被打断／偏好改变 | 呈现取消旧实例，立即采用最新数据；不回滚成功写入 |
| 动效API不支持 | 动画降级为即时静态反馈，业务动作仍可用；研发验证功能探测 |
| 样式加载失败 | HTML原生控件仍提供操作；原型视觉不代表此情况通过 |
| 页面刷新／关闭 | 草稿丢弃；最后成功保存记录再次加载；筛选默认全部 |

Owner支持并决定后续恢复需求；产品没有RTO/RPO／高可用服务承诺。

## 7. 质量属性、技术策略与退出

沿用原生HTML/CSS/JS和现有管理逻辑；新增CSS网格与有界动画，不引入框架／外部动画库。候选“整批退出再入场／FLIP位移重排”增加幽灵节点、焦点恢复和取消责任，当前推荐不用；“即时数据＋少量入场”保护快速管理。方案比较不改变已批准业务边界，具体动效已获A-001批准。

质量门槛与证据：四宽度无页面级溢出；44px主要目标；书名完整换行；100本动画最多12张、最长292ms；管理永不等待完成。实际原型check覆盖与限制见 [验证](../../../05-validation/tasks/76/design-validation.md)。不以截图证明GPU性能、帧率或精确事件时序。

数据迁移：无；首次打开不写回。退出／回退：可撤回本次HTML/CSS/动效改动，继续读取同一存储数组，不能通过清空数据回滚。可信变化只有响应式及反馈实现；未来服务需求重新审批，不预造适配器。

专家路由：已读取路由参考；本轮纯已有前端表现变更，无供应商、分布式、身份、云／成本的新决策，未启动专项专家或子Agent，不自行扩大审查对象。
