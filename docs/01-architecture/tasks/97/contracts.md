- HTML文字节点呈现；不添加title依赖、隐藏文本副本、ARIA版本副本、焦点或动态播报，不通过用户输入插值。

- 无API或版本事件，无新增字段、服务、缓存、查询参数、配置文件、网络请求和持久存储键。

原localStorage键 `page-between-reading-list`，原JSON数组记录 `{title: string, read: boolean}`，书名规则和序位沿用既有 app.js。不存储version字段或读版本日志，不迁移或重排数据。仅打开、查看版本、筛选、刷新必须保持原始字节值不变且0次新增 `setItem`。业务操作仍按既有实现写入，版本不得干预。
